# Images

Board photos used in the documentation. All were re-encoded to strip EXIF/GPS
and resized to at most 1600 px on the long edge. The originals are not included.

| File | Shows |
|---|---|
| `panel-pcb.jpg` | Button panel PCB (bottom): ASR5601S (U1), STM8S003K3 (U2), J3, J2 cable |
| `panel-front.jpg` | Button panel top side: 8 tactile buttons (K1–K8), RGB LEDs, case marking |
| `panel-connectors.jpg` | Panel PCB with the J3 programming header and cable |
| `panel-angle.jpg` | Panel PCB from another angle |
| `base-unit.jpg` | Base/output unit inside its case: fuses, output terminals, PCB |
| `base-stm8.jpg` | Base MCU close-up: STM8S003F3P6 (TSSOP-20) |
| `terminal-positions.jpg` | Lid label with the terminal/fuse order (1–2 = 30 A … 7–8 = 5 A) |
| `output-stage.jpg` | D30PW40A MOSFETs beside the fuse holders |
| `mosfet-d30pw40a.jpg` | D30PW40A marking close-up |

These are photographs of hardware owned by the author. They are included to
document the teardown; no personal or location metadata is retained.
