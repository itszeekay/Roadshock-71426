# ASR560X datasheet

Source: ASR560X Series Datasheet V1.4.0, 2023-09-18.
Original vector PDF: 2,045,676 bytes, 46 pages. It is not included.

Included:

| File | What it is |
|---|---|
| `../drive/ASR560X_Datasheet_V1.4.0_EN.ocr.txt` | Page-marked OCR text. Table rows stay in reading order. |
| `../drive/ASR560X_Datasheet_V1.4.0_EN.print_150dpi.pdf` | 150 dpi print of the datasheet. |

The OCR is derived from a raster print. Body text is usable, but table cells and
`l/1` or `O/0` pairs can be wrong. Use the print PDF for exact table cells.

The original vector PDF and the saved share page are not included. The

If ASR or a rights holder asks for removal, the files will be removed.
